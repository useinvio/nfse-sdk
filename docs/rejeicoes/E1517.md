# E1517: Não é permitido informar o grupo de informações de IBS/CBS da NFS-e quando o grupo de inf…

Rejeição **E1517** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Não é permitido informar o grupo de informações de IBS/CBS da NFS-e quando o grupo de informações de IBS/CBS da DPS não for informado.

## Regra de negócio

> Se o grupo de informações de IBS/CBS da DPS (NFSe/infNFSe/DPS/infDPS/IBSCBS/) não for informado,
> então não é permitido informar o grupo de informações de IBS/CBS da NFS-e.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/IBSCBS`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E1517`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
