# E0959: cClassTrib não pertence ao grupo CST indicado.

Rejeição **E0959** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> cClassTrib não pertence ao grupo CST indicado.

## Regra de negócio

> Código da classificação tributária - cClassTrib informado não pertence ao grupo do CST para IBS/CBS informado
> 3 primeiros dígitos do cClassTrib devem ser iguais ao CST

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/IBSCBS/valores/trib/gIBSCBS/cClassTrib`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
```
