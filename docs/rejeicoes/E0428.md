# E0428: O valor do serviço deve ser maior ou igual ao somatório dos valores informados para Desco…

Rejeição **E0428** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> O valor do serviço deve ser maior ou igual ao somatório dos valores informados para Desconto Incondicionado, Desconto Condicionado, Deduções/Reduções, Benefício Municipal, valores de tributos devidos CP, IRRF, CSLL e ISSQN se o valor deste tributo for retido.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/valores/vServPrest/vServ`
- Nível 2: regra nacional, para todos os municípios do Sistema Nacional NFS-e.
- Planilha: RN DPS_NFS-e
