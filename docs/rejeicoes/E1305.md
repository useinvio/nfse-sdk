# E1305: É obrigatório informar  o código do local de incidência quando o campo referente à tribut…

Rejeição **E1305** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> É obrigatório informar  o código do local de incidência quando o campo referente à tributação do ISSQN indicar Operação Tributável.

## Regra de negócio

> É obrigatório informar o código do local de incidência quando o serviço prestado for uma operação tributável, ou seja, o campo referente à tributação do ISSQN (tribISSQN) é igual a "1 - Operação Tributável", (tribISSQN = 1).

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/cLocIncid`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e
