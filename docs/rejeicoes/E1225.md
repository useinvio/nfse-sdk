# E1225: Falha na decodificação da base 64 da área de dados

Rejeição **E1225** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Falha na decodificação da base 64 da área de dados

## Regra de negócio

> Falha na descompactado da base 64.

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E1225`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
