# E1235: Falha no esquema XML do DF-e.

Rejeição **E1235** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Falha no esquema XML do DF-e.

## Com o @useinvio/nfse-sdk

O XML não passou no XSD oficial. Valide localmente antes de enviar com `validateDpsXmlAgainstXsd(xml)` (ou `nfse validate nota.json`): o SDK usa os mesmos schemas v1.01 e mostra a linha e o elemento do problema.

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E1235`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
