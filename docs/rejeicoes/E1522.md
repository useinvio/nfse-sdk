# E1522: O percentual redutor para compras governamentais (IBS/CBS) não deve ser informado.

Rejeição **E1522** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> O percentual redutor para compras governamentais (IBS/CBS) não deve ser informado.

## Regra de negócio

> O percentual redutor para compras governamentais só deve ser informando se tpEnteGov foi informado na DPS.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/IBSCBS/pRedutor`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e
