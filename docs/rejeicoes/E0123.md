# E0123: O preenchimento do nome empresarial é obrigatório quando o prestador for identificado com…

Rejeição **E0123** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> O preenchimento do nome empresarial é obrigatório quando o prestador for identificado com NIF.

## Regra de negócio

> Se NIF do prestador for preenchido então o campo xNome deve ser preenchido obrigatoriamente.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/prest/xNome`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e
