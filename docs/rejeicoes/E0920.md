# E0920: O código do município para o endereço do destinatário do serviço não existe conforme tabe…

Rejeição **E0920** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> O código do município para o endereço do destinatário do serviço não existe conforme tabela de município do IBGE.

## Regra de negócio

> O código do município para o endereço do destinatário do serviço não existe, conforme tabela IBGE.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/IBSCBS/dest/end/endNac/cMun`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));

```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E0920`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
