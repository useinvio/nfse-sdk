# E1578: Alíquota do Município para IBS incorreta.

Rejeição **E1578** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Alíquota do Município para IBS incorreta.

## Regra de negócio

> A alíquota do Município para IBS deve ser igual ao valor IBSCBS/gIBSCBS/gIBSMun/pIBSMun retornado pela Calculadora

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/IBSCBS/valores/mun/pIBSMun`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e
