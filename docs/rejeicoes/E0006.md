# E0006: Ambiente informado diverge do ambiente de recebimento para o qual o emitente enviou a DPS.

Rejeição **E0006** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Ambiente informado diverge do ambiente de recebimento para o qual o emitente enviou a DPS.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/tpAmb`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e

## Com o @useinvio/nfse-sdk

O `tpAmb` da DPS difere do ambiente para onde ela foi enviada. Com JSON, o SDK preenche `tpAmb` a partir de `ambiente`; com XML pronto, `emitirNfse` recusa a divergência antes de enviar. Veja [Ambientes](../referencia/ambientes.md).

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E0006`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
