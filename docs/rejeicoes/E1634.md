# E1634: Certificado Digital fora do padrão estabelecido.

Rejeição **E1634** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Certificado Digital fora do padrão estabelecido.

## Regra de negócio

> Certificado Digital da assinatura fora do padrão estabelecido pelo Sistema Nacional NFS-e:
>
> - Versão diferente de 3;
> - Se informado, Basic Constraint deve ser true (não pode ser Certificado de AC);
> - KeyUsage não define 'Assinatura Digital' e 'Não Recusa';
> - Falta a extensão de CNPJ (OtherName - OID=2.16.76.1.3.3) ou CPF (OtherName - OID=2.16.76.1.3.1);
> - Certificado Raiz difere da 'ICP-Brasil'.

## Onde se aplica

- Campo no XML: `NFSe/Signature`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E1634`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
