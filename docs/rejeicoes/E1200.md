# E1200: Certificado de Transmissão Inválido

Rejeição **E1200** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Certificado de Transmissão Inválido

## Regra de negócio

> Certificado de Transmissor Inválido:
> - Certificado de Transmissor inexistente na mensagem
> - Versão difere "3"
> - Se informado o Basic Constraint deve ser true (não pode ser Certificado de AC)
> - KeyUsage não define "Autenticação Cliente"

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E1200`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
