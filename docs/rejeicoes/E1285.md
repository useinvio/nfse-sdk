# E1285: O CPF do emitente não corresponde ao CPF do informado conforme o tipo de emitente informa…

Rejeição **E1285** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> O CPF do emitente não corresponde ao CPF do informado conforme o tipo de emitente informado na DPS.

## Regra de negócio

> Verificar se o CPF do emitente corresponde ao CPF informado para prestador ou tomador ou intermediário, conforme o valor do campo tpEmit informado na DPS.
> tpemit = 1 - Prestador, tpemit = 2 - Tomador, tpemit = 3 - Intermediário,

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/emit/CPF`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E1285`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
