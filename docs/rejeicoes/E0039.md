# E0039: O município emissor informado na DPS deve estar parametrizado para utilizar os emissores…

Rejeição **E0039** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> O município emissor informado na DPS deve estar parametrizado para utilizar os emissores públicos nacionais, conforme parametrização do município no Sistema Nacional NFS-e.

## Regra de negócio

> O município emissor informado na DPS deve estar parametrizado para utilizar os emissores públicos nacionais, conforme parametrização do município no Sistema Nacional NFS-e.
>
> Exceto quando o emitente da DPS for MEI na data de competência da emissão da NFS-e.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/cLocEmi`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e
