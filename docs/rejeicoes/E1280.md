# E1280: CNPJ informado para o emitente da NFS-e é inválido (verificar DV).

Rejeição **E1280** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> CNPJ informado para o emitente da NFS-e é inválido (verificar DV).

## Regra de negócio

> Verificar se o CNPJ informado para o emitente da NFS-e é válido (verificar DV).

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/emit/CNPJ`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E1280`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
