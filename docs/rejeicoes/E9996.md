# E9996: Nesta versão da aplicação, não é permitida a emissão de NFS-e pelo tomador ou intermediár…

Rejeição **E9996** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Nesta versão da aplicação, não é permitida a emissão de NFS-e pelo tomador ou intermediário.

## Regra de negócio

> Se a DPS for emitida pelo tomador ou intermendiário (tpEmit = 2 ou 3), então a DPS deve ser rejeitada pelo sistema.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/tpEmit`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E9996`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
