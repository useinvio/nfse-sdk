# E0298: O grupo de informações de endereço no exterior deve ser informado obrigatoriamente quando…

Rejeição **E0298** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> O grupo de informações de endereço no exterior deve ser informado obrigatoriamente quando o intermediário for identificado pelo NIF e o emitente por CNPJ.

## Regra de negócio

> Se o NIF do intermediário de serviço foi informado e o emitente da DPS for identificado por CNPJ, então o grupo de informações de endereço no exterior do tomador do serviço deve ser informado obrigatoriamente.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/interm/end/endExt`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {

```
