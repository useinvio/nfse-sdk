# E1302: Exceto para o campo vLiq, não é permitido informar os demais campos do grupo valores para…

Rejeição **E1302** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Exceto para o campo vLiq, não é permitido informar os demais campos do grupo valores para prestador de serviço optante do simples nacional do tipo MEI.

## Regra de negócio

> Exceto para o campo vLiq, não é permitido informar os demais campos do grupo valores quando o prestador é optante do simples nacional do tipo MEI (opSimpNac = 2).

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/valores`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e
