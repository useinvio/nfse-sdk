# E0061: Os campos identificação do Tomador (se identificado na DPS), data de competência (dCompet…

Rejeição **E0061** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Os campos identificação do Tomador (se identificado na DPS), data de competência (dCompet), e valor do serviço (vServ), não podem ser alterados quando a opção do simples nacional for MEI (opSimpNac = 2) ou ME/EPP (opSimpNac = 3).

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/substchSubstda`
- Nível 2: regra nacional, para todos os municípios do Sistema Nacional NFS-e.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E0061`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
