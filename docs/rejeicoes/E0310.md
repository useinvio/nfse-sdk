# E0310: O código de tributação nacional informado não existe conforme a lista de serviços naciona…

Rejeição **E0310** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> O código de tributação nacional informado não existe
> conforme a lista de serviços nacional do Sistema Nacional NFS-e.

## Regra de negócio

> Verificar se o código de tributação nacional informado existe conforme a lista de serviços nacional do Sistema Nacional NFS-e.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/serv/cServ/cTribNac`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E0310`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
