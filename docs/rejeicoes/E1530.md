# E1530: Valor da Base de cálculo para IBS/CBS incorreto.

Rejeição **E1530** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Valor da Base de cálculo para IBS/CBS incorreto.

## Regra de negócio

> O valor da base de cálculo do IBS/CBS (vBC) é calculado a partir de valores informados na NFS-e:
>
> (de 01/01/2026 até 31/12/2026)
> vBC = vServ - descIncond – vCalcReeRepRes – vISSQN – vPIS - vCOFINS
> ou
> (de 01/01/2027 até 31/12/2032)
> vBC = vServ - descIncond – vCalcReeRepRes – vISSQN

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/IBSCBS/valores/vBC`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e
