# E1831: O pedido de registro de evento não pode ser validado pois a NFS-e indicada não existe no…

Rejeição **E1831** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo II - Leiaute e Regras de Negocio de Eventos v1.01 (22/01/2026).

## Mensagem oficial

> O pedido de registro de evento não pode ser validado pois a NFS-e indicada não existe no Ambiente de Dados Nacional NFS-e.

## Regra de negócio

> A NFS-e indicada não existe no ADN NFS-e.

## Onde se aplica

- Campo no XML: `evento/pedRegEvento/infPedReg/chNFSe`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN EVENTO_PED.REG.EVENTO

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E1831`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
