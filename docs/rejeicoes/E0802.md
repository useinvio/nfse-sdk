# E0802: Já existe um documento fiscal eletrônico identificado com este id no Sistema Nacional NFS…

Rejeição **E0802** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo II - Leiaute e Regras de Negocio de Eventos v1.01 (22/01/2026).

## Mensagem oficial

> Já existe um documento fiscal eletrônico identificado com este id no Sistema Nacional NFS-e.

## Regra de negócio

> O id do evento gerado já existe no ADN.

## Onde se aplica

- Campo no XML: `evento/infEvento/id`
- Planilha: RN EVENTO_PED.REG.EVENTO

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E0802`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
