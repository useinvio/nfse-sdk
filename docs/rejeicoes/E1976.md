# E1976: Não existe o identificador de bloqueio informado neste evento para desbloqueio.

Rejeição **E1976** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo II - Leiaute e Regras de Negocio de Eventos v1.01 (22/01/2026).

## Mensagem oficial

> Não existe o identificador de bloqueio informado neste evento para desbloqueio.

## Regra de negócio

> O evento de Evento de Desbloqueio de NFS-e deve ser rejeitado se o identificador do bloqueio de oficio, indicado neste evento, não existir.

## Onde se aplica

- Campo no XML: `evento/pedRegEvento/infPedReg/e305103/idBloqOfic`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN EVENTO_PED.REG.EVENTO
