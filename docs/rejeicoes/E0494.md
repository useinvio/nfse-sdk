# E0494: O código do município informado na DPS para o endereço do fornecedor do serviço não exist…

Rejeição **E0494** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> O código do município informado na DPS para o endereço do fornecedor do serviço não existe conforme tabela de município do IBGE.

## Regra de negócio

> O código do município informado para o endereço do fornecedor não existe, conforme tabela de municípios do IBGE.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/valores/vDedRed/documentos/docDedRed/fornec/end/endNac/cMun`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e
