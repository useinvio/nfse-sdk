# E0854: Somente é permitio declarar informações de IBS/CBS a partir da versão 1,01 da DPS.

Rejeição **E0854** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Somente é permitio declarar informações de IBS/CBS a partir da versão 1,01 da DPS.

## Regra de negócio

> Somente é permitio declarar informações de IBS/CBS a partir da versão 1.01 da DPS.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/IBSCBS`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E0854`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
