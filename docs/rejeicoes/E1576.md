# E1576: Grupo crédito presumido para CBS deve ser informado.

Rejeição **E1576** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Grupo crédito presumido para CBS deve ser informado.

## Regra de negócio

> O grupo de crédito presumido para CBS deve ser informado se o código do crédito presumido - cCredPres também foi informado na DPS.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/IBSCBS/totCIBS/gCBS/gCBSCredPres`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e
