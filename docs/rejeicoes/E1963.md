# E1963: O identificador do Evento de Manifestação de NFS-e - Rejeição a ser anulado deve existir…

Rejeição **E1963** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo II - Leiaute e Regras de Negocio de Eventos v1.01 (22/01/2026).

## Mensagem oficial

> O identificador do Evento de Manifestação de NFS-e - Rejeição a ser anulado deve existir no Sistema Nacional NFS-e e corresponder a um identificador de evento de rejeição vinculada à NFS-e informada no evento.

## Onde se aplica

- Campo no XML: `evento/pedRegEvento/infPedReg/e205208/idEvManifRej`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN EVENTO_PED.REG.EVENTO

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E1963`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
