# E0488: CPF do fornecedor informado na DPS não encontrado no cadastro CPF.

Rejeição **E0488** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> CPF do fornecedor informado na DPS não encontrado no cadastro CPF.

## Regra de negócio

> CPF informado na DPS é inexistente no cadastro CPF.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/valores/vDedRed/documentos/docDedRed/fornec/CPF`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E0488`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
