# E1638: A assinatura deve ser feita com o certificado digital do municiípio emissor da NFS-e.

Rejeição **E1638** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> A assinatura deve ser feita com o certificado digital do municiípio emissor da NFS-e.

## Regra de negócio

> A assinatura deve ser feita com o certificado digital do município emissor da NFS-e.

## Onde se aplica

- Campo no XML: `NFSe/Signature`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E1638`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
