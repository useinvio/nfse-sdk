# E1274: O ambiente gerador da NFS-e não está de acordo com a definição 1 (Sistema Próprio do Muni…

Rejeição **E1274** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> O ambiente gerador da NFS-e não está de acordo com a definição 1 (Sistema Próprio do Município) ou 2 (Sefin Nacional).

## Regra de negócio

> Verificar se o ambiente gerador da NFS-e está de acordo com a definição:
> 1- Sistema Próprio do Município, para as NFS-e compartilhadas pelo município para o ADN, ou
> 2 - Sefin Nacional NFS-e, para as NFS-e emitidas pela Sefin ou recepcionadas via API "Bypass".

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/ambGer`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E1274`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
