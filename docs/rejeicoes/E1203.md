# E1203: Certificado de Transmissão expirado

Rejeição **E1203** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Certificado de Transmissão expirado

## Regra de negócio

> Validade do Certificado (data início e data fim)

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E1203`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
