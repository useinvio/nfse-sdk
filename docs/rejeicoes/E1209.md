# E1209: Certificado de Transmissão sem CNPJ ou CPF.

Rejeição **E1209** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Certificado de Transmissão sem CNPJ ou CPF.

## Regra de negócio

> Falta a extensão de CNPJ ou CPF no Certificado (OtherName - OID=2.16.76.1.3.3)

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E1209`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
