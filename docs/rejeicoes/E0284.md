# E0284: O intermediário de serviço, quando emitente da DPS, somente pode ser identificado pelo CN…

Rejeição **E0284** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> O intermediário de serviço, quando emitente da DPS, somente pode ser identificado pelo CNPJ ou CPF.

## Regra de negócio

> Se o campo tpEmit for ígual a 3, então cNaoNIF do intermediário não pode ser informado.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/interm/cNaoNIF`
- Nível 2: regra nacional, para todos os municípios do Sistema Nacional NFS-e.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E0284`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
