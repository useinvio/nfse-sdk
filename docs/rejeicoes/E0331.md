# E0331: É obrigatório prestar informações de comércio exterior para as situações de importação de…

Rejeição **E0331** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> É obrigatório prestar informações de comércio exterior para as situações de importação de serviços.

## Regra de negócio

> IMPORTAÇÃO DE SERVIÇO
>
> Se o emitente for o tomador (tpEmit = 2) ou o intermediário de serviço (tpEmit = 3),  e qualquer um dos campos abaixo for informado na DPS
>
> País no exterior do endereço do prestador do serviço ou
> cPaisPrestacao é informado,
>
> então o grupo de informações de comércio exterior devem ser informados.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/serv/comExt`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';
```
