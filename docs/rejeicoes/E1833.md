# E1833: Somente é permitido um único evento do tipo Manifestação de NFS-e (Confirmação e Rejeição…

Rejeição **E1833** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo II - Leiaute e Regras de Negocio de Eventos v1.01 (22/01/2026).

## Mensagem oficial

> Somente é permitido um único evento do tipo Manifestação de NFS-e (Confirmação e Rejeição), por não emitente da NFS-e indicada no evento.

## Regra de negócio

> Somente é permitido um único evento do tipo Manifestação de NFS-e (Confirmação e Rejeição), se o autor do evento, informado nos campos CNPJAutor ou CPFAutor, corresponder aos possíveis não emitentes da NFS-e indicada pela chave de acesso.

## Onde se aplica

- Campo no XML: `evento/pedRegEvento/infPedReg/chNFSe`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN EVENTO_PED.REG.EVENTO

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E1833`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
