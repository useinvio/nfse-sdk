# E1584: Grupo de tributação regular deve ser informado para o cClassTribIBSCBS indicado.

Rejeição **E1584** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Grupo de tributação regular deve ser informado para o cClassTribIBSCBS indicado.

## Regra de negócio

> O grupo de tributação regular deve ser informado se o indicador para tributação regular (exigeGrupoTributacaoRegular) para o código da classificação tributária - cClassTribIBSCBS for igual a true

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/IBSCBS/totCIBS/gTribRegular`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e
