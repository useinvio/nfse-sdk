# E0268: CPF do intermediário não encontrado no cadastro CPF.

Rejeição **E0268** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> CPF do intermediário não encontrado no cadastro CPF.

## Regra de negócio

> CPF intermediário inexistente no cadastro CPF na data de competência informada na DPS.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/interm/CPF`
- Nível 2: regra nacional, para todos os municípios do Sistema Nacional NFS-e.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {

```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E0268`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
