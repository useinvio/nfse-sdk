# E0827: Não é permitido realizar um Evento de Cancelamento para NFS-e que possua Evento de Tribut…

Rejeição **E0827** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo II - Leiaute e Regras de Negocio de Eventos v1.01 (22/01/2026).

## Mensagem oficial

> Não é permitido realizar um Evento de Cancelamento para NFS-e que possua Evento de Tributos Recolhidos vinculado, conforme parametrização do município de incidência do ISSQN da NFS-e.

## Onde se aplica

- Campo no XML: `evento/pedRegEvento/infPedReg/chNFSe`
- Nível 3: regra municipal, conforme a parametrização do município.
- Planilha: RN EVENTO_PED.REG.EVENTO

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E0827`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
