# E0207: CPF do tomador não encontrado no cadastro CPF.

Rejeição **E0207** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> CPF do tomador não encontrado no cadastro CPF.

## Regra de negócio

> CPF do tomador inexistente no cadastro CPF na data de competência informada na DPS.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/toma/CPF`
- Nível 2: regra nacional, para todos os municípios do Sistema Nacional NFS-e.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';
```
