# E0905: O grupo de documentos referenciados deve ser informado para o tipo de operação (tpOper).

Rejeição **E0905** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> O grupo de documentos referenciados deve ser informado para o tipo de operação (tpOper).

## Regra de negócio

> O grupo de documentos referenciados (gRefNFSe) deve ser informado quando tpOper = 2 ou 3.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/IBSCBS/gRefNFSe`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E0905`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
