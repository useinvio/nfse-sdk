# E0115: Valor 0 para o motivo da não informação do NIF do prestador não é permitido na Sefin do S…

Rejeição **E0115** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Valor 0 para o motivo da não informação do NIF do prestador não é permitido na Sefin do Sistema Nacional NFS-e.

## Regra de negócio

> Se o valor do campo cNaoNIF do prestador, informado na DPS, for 0, então a DPS deve ser rejeitada.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/prest/cNaoNIF`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e
