# E1566: Valor do diferimento para o IBS estadual deve ser informado.

Rejeição **E1566** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Valor do diferimento para o IBS estadual deve ser informado.

## Regra de negócio

> O valor do diferimento para o IBS estadual deve ser informado se foi informada, na DPS, a alíquota para o diferimento do IBS estadual - pDifUF.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/IBSCBS/totCIBS/gIBS/gIBSUFTot/vDifUF`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e
