# E0942: Outros documentos ficais fiscais não podem ser informados quando a data de competência fo…

Rejeição **E0942** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Outros documentos ficais fiscais não podem ser informados quando a data de competência for posterior a 31 de dezembro de 2025.

## Regra de negócio

> Outros documentos fiscais só podem ser informados se a data de competência do documento (dtCompDoc) for anterior a 31/12/2025.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/IBSCBS/valores/gReeRepRes/documentosdocFiscalOutro`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e

import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';
