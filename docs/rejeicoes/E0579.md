# E0579: É obrigatório informar pRedBCBM quando o código de identificação do Benefício Municipal (…

Rejeição **E0579** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> É obrigatório informar pRedBCBM quando o código de identificação do Benefício Municipal (nBM) for um benefício do tipo Redução de Base de Cálculo por percentual.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/valores/trib/tribMun/BM/pRedBCBM`
- Nível 3: regra municipal, conforme a parametrização do município.
- Planilha: RN DPS_NFS-e
