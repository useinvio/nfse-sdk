# E0468: Informar, obrigatoriamente, o campo de descrição no caso ideDedRed igual a 99 – Outras de…

Rejeição **E0468** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Informar, obrigatoriamente, o campo de descrição no caso ideDedRed igual a 99 – Outras deduções.

## Regra de negócio

> O campo de descrição deve ser informado no caso de tpDedRed igual a 99 – Outras deduções.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/valores/vDedRed/documentos/docDedRed/xDescOutDed`
- Nível 2: regra nacional, para todos os municípios do Sistema Nacional NFS-e.
- Planilha: RN DPS_NFS-e
