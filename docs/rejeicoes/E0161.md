# E0161: NFS-e cujo emitente for MEI somente poderá ser compartilhada pelo município com o ADN se…

Rejeição **E0161** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> NFS-e cujo emitente for MEI somente poderá ser compartilhada pelo município com o ADN se a data de competência, informada na NFS-e, for menor ou igual a 31/08/2023.

## Regra de negócio

> Quando o emitente for MEI a NFS-e poderá ser compartilhada pelo município com o ADN somente se a data de competência for igual ou menor que 31/08/2023.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/prest/regTrib/opSimpNac`
- Nível 2: regra nacional, para todos os municípios do Sistema Nacional NFS-e.
- Planilha: RN DPS_NFS-e
