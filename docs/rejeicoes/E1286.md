# E1286: O código do município do emitente da NFS-e difere do código do municipio emissor informad…

Rejeição **E1286** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> O código do município do emitente da NFS-e difere do código do municipio emissor informado na NFS-e.

## Regra de negócio

> Verificar se o código do município do emitente da NFS-e corresponde ao código do município emissor (cLocEmi) informado na NFS-e.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/emit/enderNac/cMun`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E1286`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
