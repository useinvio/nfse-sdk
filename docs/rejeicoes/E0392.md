# E0392: O grupo de informações de Atividade/Evento não é permitido quando o código de tributação…

Rejeição **E0392** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> O grupo de informações de Atividade/Evento não é permitido quando o código de tributação nacional não pertencer ao item 12 da lista de serviços, com exceção do código 99.01.01.

## Regra de negócio

> Se o código de tributação nacional não pertencer ao item 12 da lista de serviços, então o grupo de informações de Atividade/Evento não é permitido.
> *Exceção: O grupo de informações de Atividade/Evento pode ser informado se o código de tributação nacional for o 99.01.01.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/serv/atvEvento`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e
