# E0460: Informe uma chave de NF-e válida.

Rejeição **E0460** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Informe uma chave de NF-e válida.

## Regra de negócio

> Chave de NF-e inválida.
>
> 1 - Verificar DV da chave de NF-e informada neste campo desta DPS;

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/valores/vDedRed/documentos/docDedRed/chNFe`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E0460`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
