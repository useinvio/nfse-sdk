# E1989: A assinatura é obrigatória quando for enviado para o Web Service.

Rejeição **E1989** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo II - Leiaute e Regras de Negocio de Eventos v1.01 (22/01/2026).

## Mensagem oficial

> A assinatura é obrigatória quando for enviado para o Web Service.

## Regra de negócio

> É obrigatória a existência da assinatura do Pedido de Registro de Evento quando for enviado para Web Service.

## Onde se aplica

- Campo no XML: `evento/pedRegEvento/Signature`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN EVENTO_PED.REG.EVENTO

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E1989`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
