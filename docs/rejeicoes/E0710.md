# E0710: Para MEI pTotTribSN nunca poderá ser informado.

Rejeição **E0710** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Para MEI pTotTribSN nunca poderá ser informado.

## Regra de negócio

> Se a situação do emitente da DPS perante o Simples Nacional na data de competência informada for MEI, o choice pTotTribSN nunca poderá ser informado.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/valores/trib/totTrib/pTotTribSN`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E0710`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
