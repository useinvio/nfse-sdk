# E1242: Tipo DF-e não tratado pelo Sistema Nacional NFS-e.

Rejeição **E1242** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Tipo DF-e não tratado pelo Sistema Nacional NFS-e.

## Regra de negócio

> Validar os tipos de DF-e tratados pelo Sistema Nacional NFS-e.

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E1242`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
