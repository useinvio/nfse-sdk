# E0204: CNPJ ou CPF do tomador não foi informado, mas existe uma indicação para retenção do ISSQN…

Rejeição **E0204** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> CNPJ ou CPF do tomador não foi informado, mas existe uma indicação para retenção do ISSQN na DPS no campo de tipo de "Retenção do ISSQN".

## Regra de negócio

> Se a DPS indicar retenção pelo tomador (tpRetISSQN = 2), então o tomador deve ser identificado por CNPJ ou CPF.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/toma/CNPJ`
- Nível 2: regra nacional, para todos os municípios do Sistema Nacional NFS-e.
- Planilha: RN DPS_NFS-e
