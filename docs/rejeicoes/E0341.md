# E0341: Valor 0 para o Mecanismo de apoio/fomento ao Comércio Exterior utilizado pelo prestador d…

Rejeição **E0341** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Valor 0 para o Mecanismo de apoio/fomento ao Comércio Exterior utilizado pelo prestador do serviço não é permitido na Sefin do Sistema Nacional NFS-e.

## Regra de negócio

> Se o valor do campo mecAFComexP for 0, então a DPS deve ser rejeitada.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/serv/comExt/mecAFComexP`
- Nível 2: regra nacional, para todos os municípios do Sistema Nacional NFS-e.
- Planilha: RN DPS_NFS-e
