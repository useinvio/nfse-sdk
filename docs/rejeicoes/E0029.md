# E0029: O motivo da emissão não pode ser preenchido se o emitente for o prestador de serviço.

Rejeição **E0029** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> O motivo da emissão não pode ser preenchido se o emitente for o prestador de serviço.

## Regra de negócio

> Se o emitente for o prestador de serviço (tpEmit = 1), então este campo não deve ser preenchido.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/cMotivoEmisTI`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E0029`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
