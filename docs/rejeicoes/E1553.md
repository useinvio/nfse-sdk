# E1553: Percentual redutor de alíquota para a CBS incorreto.

Rejeição **E1553** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Percentual redutor de alíquota para a CBS incorreto.

## Regra de negócio

> O percentual redutor de alíquota para a CBS deve ser igual ao valor IBSCBS/gIBSCBS/gCBS/gRed/pRedAliq retornado pela Calculadora

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/IBSCBS/valores/fed/pRedAliqCBS`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e
