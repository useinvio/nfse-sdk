# E0082: CNPJ do emitente prestador não encontrado no cadastro CNPJ na data de competência.

Rejeição **E0082** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> CNPJ do emitente prestador não encontrado no cadastro CNPJ na data de competência.

## Regra de negócio

> CNPJ do prestador não existe no cadastro CNPJ na data de competência informada na DPS.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/prest/CNPJ`
- Nível 2: regra nacional, para todos os municípios do Sistema Nacional NFS-e.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E0082`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
