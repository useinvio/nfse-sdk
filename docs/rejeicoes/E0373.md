# E0373: Código CIB inválido.

Rejeição **E0373** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Código CIB inválido.

## Regra de negócio

> Código do Cadastro Imobiliário Brasileito - CIB deve ser um código válido - 7 caracteres + DV

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/serv/obra/cCIB`
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E0373`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
