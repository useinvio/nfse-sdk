# E0850: É permitido declarar informações de IBS/CBS somente a partir da data de competência 01/01…

Rejeição **E0850** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> É permitido declarar informações de IBS/CBS somente a partir da data de competência 01/01/2026.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/IBSCBS`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E0850`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
