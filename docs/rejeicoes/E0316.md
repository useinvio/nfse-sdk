# E0316: Código da lista NBS informado inexistente tabela de NBS do sistema.

Rejeição **E0316** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Código da lista NBS informado inexistente tabela de NBS do sistema.

## Regra de negócio

> O código da lista NBS informado na DPS não existe, conforme tabela NBS do ANEXO_B-NBS2-LISTA_SERVICO_NACIONAL-SNNFSe do Manual Integrado do Sistema Nacional NFS-e.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/serv/cServ/cNBS`
- Nível 2: regra nacional, para todos os municípios do Sistema Nacional NFS-e.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E0316`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
