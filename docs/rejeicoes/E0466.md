# E0466: Informe um código de município existente para o documento de nota, conforme tabela de mun…

Rejeição **E0466** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Informe um código de município existente para o documento de nota, conforme tabela de municípios do IBGE.

## Regra de negócio

> O código do município informado para o documento de nota não existe, conforme tabela de municípios do IBGE.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/valores/vDedRed/documentos/docDedRed/NFSeMun/cMunNFSeMun`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E0466`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
