# E0315: Não é permitido informar 000 para o codigo de tributação municipal na DPS.

Rejeição **E0315** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Não é permitido informar 000 para o codigo de tributação municipal na DPS.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/serv/cServ/cTribMun`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e
