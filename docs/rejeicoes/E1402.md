# E1402: Quando é informado o subitem 200101 para o código de tributação nacional (cTribNac), não…

Rejeição **E1402** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Quando é informado o subitem 200101 para o código de tributação nacional (cTribNac), não é permitido informar 0000000, que representa "Águas Marítimas", para o local de prestação do serviço (cLocPrestacao).

## Regra de negócio

> Se informado o subitem 200101 para o código de tributação nacional (cTribNac),
> então não é permitido informar 0000000, que representa "Águas Marítimas", para o local de prestação do serviço (cLocPrestacao).

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/serv/locPrest/cLocPrestacao`
- Planilha: RN DPS_NFS-e
