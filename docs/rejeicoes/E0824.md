# E0824: NFS-e sem indentificação do tomador do serviço não pode ser cancelada, conforme parametri…

Rejeição **E0824** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo II - Leiaute e Regras de Negocio de Eventos v1.01 (22/01/2026).

## Mensagem oficial

> NFS-e sem indentificação do tomador do serviço não pode ser cancelada, conforme parametrização do município emissor da NFS-e.

## Regra de negócio

> Não pode ocorrer o cancelamento de NFS-e que não esteja identificado o tomador de serviço, conforme parametrização do município emissor da NFS-e.

## Onde se aplica

- Campo no XML: `evento/pedRegEvento/infPedReg/chNFSe`
- Nível 3: regra municipal, conforme a parametrização do município.
- Planilha: RN EVENTO_PED.REG.EVENTO

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E0824`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
