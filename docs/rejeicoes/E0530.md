# E0530: O sistema considera este cenário para a prestação de serviço informada na DPS uma exporta…

Rejeição **E0530** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> O sistema considera este cenário para a prestação de serviço informada na DPS uma exportação de serviço. Não é permitido ao emitente da DPS informar que a prestação de serviço se trata de uma operação tributável.

## Regra de negócio

> Não é permitido ao emitente informar se tratar de uma situação de operação tributável (tribISSQN = 1) para os cenários 26, 54, 92, 96, 106, 110, conforme a planilha "EXPORTACAO_EMISSÃO_NFS-e".

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/valores/trib/tribMun/tribISSQN`
- Nível 2: regra nacional, para todos os municípios do Sistema Nacional NFS-e.
- Planilha: RN DPS_NFS-e
