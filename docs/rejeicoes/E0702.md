# E0702: Se o valor for informado, então deve ser igual ou maior que 0 e menor ou igual o valor do…

Rejeição **E0702** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Se o valor for informado, então deve ser igual ou maior que 0 e menor ou igual o valor do serviço.

## Regra de negócio

> Se valor for informado, então deve ser igual ou maior que 0 e menor ou igual o valor do serviço.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/valores/trib/totalTrib/vTotTribvTotTribFed`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e
