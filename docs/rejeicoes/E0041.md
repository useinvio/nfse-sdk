# E0041: O município emissor não corresponde ao município do emitente MEI no CNPJ.

Rejeição **E0041** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> O município emissor não corresponde ao município do emitente MEI no CNPJ.

## Regra de negócio

> Se tpEmit for igual a 1 (prestador) e a opção pelo simples nacional for igual a 2 (MEI),
> então o município emissor deve corresponder ao município do endereço do emitente no cadastro CNPJ.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/cLocEmi`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E0041`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
