# E1329: Não é permitido informar a descrição do local de incidência quando o código do local de i…

Rejeição **E1329** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Não é permitido informar a descrição do local de incidência quando o código do local de incidência (cLocIncid) não for informado.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/xLocIncid`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E1329`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
