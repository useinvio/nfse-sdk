# E0462: NF-e não existe na base de dados do autorizador de NF-e nacional. Informe uma chave de NF…

Rejeição **E0462** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> NF-e não existe na base de dados do autorizador de NF-e nacional. Informe uma chave de NF-e existente.

## Regra de negócio

> Chave de NF-e inexistente.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/valores/vDedRed/documentos/docDedRed/chNFe`
- Nível 2: regra nacional, para todos os municípios do Sistema Nacional NFS-e.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E0462`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
