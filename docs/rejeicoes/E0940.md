# E0940: Chave DF-e incorreta.

Rejeição **E0940** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Chave DF-e incorreta.

## Regra de negócio

> A chave do Documento Fiscal eletrônico - DF-e deve estar no formato DF-e indicado no tipo.
> Verificar tamanho: NFSe - 50 dígitos e NFe e CTe - 44 dígitos

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/IBSCBS/valores/gReeRepRes/documentos/dFeNacional/chaveDFe`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {

```
