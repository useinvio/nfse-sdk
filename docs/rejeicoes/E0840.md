# E0840: O Sistema Nacional NFS-e não pode recepecionar o EVENTO DE CANCELAMENTO DE NFS-e pois, o…

Rejeição **E0840** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo II - Leiaute e Regras de Negocio de Eventos v1.01 (22/01/2026).

## Mensagem oficial

> O Sistema Nacional NFS-e não pode recepecionar o EVENTO DE CANCELAMENTO DE NFS-e pois, o evento de <nome_evento_vinculado_a_NFS-e> já está vinculado à NFS-e indicada no evento enviado, impedindo sua recepção.

## Regra de negócio

> O Sistema Nacional NFS-e deve responder à recepção do EVENTO DE CANCELAMENTO NFS-e, conforme indicado nas linhas da respectiva coluna deste evento na planilha "RN EVENTOSxEVENTOS - Sistema Nacional NFS-e".

## Onde se aplica

- Campo no XML: `evento/pedRegEvento/infPedReg/e101101`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN EVENTO_PED.REG.EVENTO

## Com o @useinvio/nfse-sdk

A NFS-e já tem um evento que impede o cancelamento (por exemplo, já foi cancelada). Consulte os eventos com `consultarEventosPorChaveAdn(chave, certificado)` antes de tentar de novo. Veja [Cancelar uma NFS-e](../guias/cancelar.md).

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E0840`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
