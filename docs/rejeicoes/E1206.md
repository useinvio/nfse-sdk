# E1206: Certificado de Transmissão - Erro de acesso a LCR

Rejeição **E1206** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Certificado de Transmissão - Erro de acesso a LCR

## Regra de negócio

> LCR do Certificado de Transmissor
> - Falta o endereço da LCR (CRL DistributionPoint)
> - LCR indisponível
> - LCR inválida

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E1206`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
