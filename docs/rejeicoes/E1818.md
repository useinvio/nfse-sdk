# E1818: Não é permitido o compartilhamento pelo município com o ADN dos eventos de manifestação d…

Rejeição **E1818** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo II - Leiaute e Regras de Negocio de Eventos v1.01 (22/01/2026).

## Mensagem oficial

> Não é permitido o compartilhamento pelo município com o ADN dos eventos de manifestação de NFS-e para confirmação ou rejeição pelos não emitentes de um NFS-e. Estes eventos devem ser emitidos pelos não emitentes da NFS-e diretamente no SEFIN NFS-e.

## Regra de negócio

> Não é permitido o compartilhamento dos seguintes eventos pelo município com o ADN são:
> 202201 - Manifestação de NFS-e de Confirmação do Prestador;
> 203202 - Manifestação de NFS-e de Confirmação do Tomador;
> 204203 - Manifestação de NFS-e de Confirmação do Intermediário;
> 202205 - Manifestação de NFS-e de Rejeição do Prestador;
> 203206 - Manifestação de NFS-e de Rejeição do Tomador;
> 204207 - Manifestação de NFS-e de Rejeição do Intermediário;

## Onde se aplica

- Campo no XML: `evento/pedRegEvento/infPedReg/id`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN EVENTO_PED.REG.EVENTO

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

  await emitirNfse(nota, certificado);

```
