# E0174: Quando o prestador da NFS-e é MEI (opSimpNac = 2) o regime especial de tributação deve se…

Rejeição **E0174** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Quando o prestador da NFS-e é MEI (opSimpNac = 2) o regime especial de tributação deve ser "Nenhum" (regEspTrib = 0).

## Regra de negócio

> O tipo de regime especial de tributação deve ser "Nenhum", quando o prestador for MEI (opSimpNac = 2).

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/prest/regTrib/regEspTrib`
- Nível 2: regra nacional, para todos os municípios do Sistema Nacional NFS-e.
- Planilha: RN DPS_NFS-e
