# E0058: Não poderá ocorrer a substituição de NFS-e com alteração da identificação do não emitente…

Rejeição **E0058** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Não poderá ocorrer a substituição de NFS-e com alteração da identificação do não emitente, conforme parametrização do município emissor da NFS-e.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/substchSubstda`
- Nível 3: regra municipal, conforme a parametrização do município.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E0058`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
