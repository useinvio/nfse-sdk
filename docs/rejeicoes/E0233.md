# E0233: O nome tomador deve ser preenchido obrigatoriamente quando o NIF do tomador for preenchid…

Rejeição **E0233** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> O nome tomador deve ser preenchido obrigatoriamente quando o NIF do tomador for preenchido.

## Regra de negócio

> Se NIF for preenchido então o campo xNome deve ser preenchido obrigatoriamente.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/toma/xNome`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e
