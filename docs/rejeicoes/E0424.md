# E0424: O valor recebido não deve ser informado na DPS quando o prestador ou tomador do serviço f…

Rejeição **E0424** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> O valor recebido não deve ser informado na DPS quando o prestador ou tomador do serviço for o emitente da DPS.

## Regra de negócio

> O valor recebido não deve ser informado na DPS quando o prestador ou tomador do serviço for o emitente da DPS
> (tpEmit = 1 ou tpEmit = 2).

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/valores/vServPrest/vReceb`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E0424`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
