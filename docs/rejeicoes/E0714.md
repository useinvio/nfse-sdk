# E0714: Arquivo enviado com erro na assinatura.

Rejeição **E0714** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Arquivo enviado com erro na assinatura.

## Regra de negócio

> A assinatura da DPS deve ser válida.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/Signature`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e

## Com o @useinvio/nfse-sdk

A assinatura não confere. Assine com o mesmo certificado usado na conexão mTLS e não altere o XML depois de assinar. `prepararNota` assina e verifica a assinatura antes do envio. Veja [Configurar o certificado A1](../guias/certificado.md).

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E0714`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
