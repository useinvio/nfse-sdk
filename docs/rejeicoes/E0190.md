# E0190: CNPJ do tomador não encontrado no cadastro CNPJ.

Rejeição **E0190** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> CNPJ do tomador não encontrado no cadastro CNPJ.

## Regra de negócio

> CNPJ do tomador não existe no cadastro CNPJ na data de competência informada na DPS.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/toma/CNPJ`
- Nível 2: regra nacional, para todos os municípios do Sistema Nacional NFS-e.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E0190`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
