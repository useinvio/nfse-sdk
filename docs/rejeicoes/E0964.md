# E0964: Grupo de tributação regular não deve ser informado.

Rejeição **E0964** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Grupo de tributação regular não deve ser informado.

## Regra de negócio

> Grupo de tributação regular não deve ser informado quando o indicador para tributação regular (exigeGrupoTributacaoRegular) para o Código da Classificação Tributária - cClassTribIBSCBS for igual a false.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/IBSCBS/valores/trib/gIBSCBS/gTribRegular`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e
