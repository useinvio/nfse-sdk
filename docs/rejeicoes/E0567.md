# E0567: É obrigatório informar vRedBCBM quando o código de identificação do Benefício Municipal (…

Rejeição **E0567** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> É obrigatório informar vRedBCBM quando o código de identificação do Benefício Municipal (nBM) for um benefício do tipo Redução de Base de Cálculo por Valor Monetário.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/valores/trib/tribMun/BM/vRedBCBM`
- Nível 3: regra municipal, conforme a parametrização do município.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {

```
