# E0541: Não existe o código de identificação do benefício municipal informado na DPS para o munic…

Rejeição **E0541** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Não existe o código de identificação do benefício municipal informado na DPS para o municipío de incidência do ISSQN.

## Regra de negócio

> O código de identificação do Benefício Municipal não existente para municipio de incidência do ISSQN.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/valores/trib/tribMun/BM/nBM`
- Nível 3: regra municipal, conforme a parametrização do município.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {

```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E0541`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
