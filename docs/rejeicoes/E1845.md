# E1845: Ambiente informado diverge do ambiente de recebimento para o qual o emitente está enviand…

Rejeição **E1845** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo II - Leiaute e Regras de Negocio de Eventos v1.01 (22/01/2026).

## Mensagem oficial

> Ambiente informado diverge do ambiente de recebimento para o qual o emitente está enviando o evento.

## Regra de negócio

> Tipo do ambiente informado difere do ambiente utilizado.

## Onde se aplica

- Campo no XML: `evento/pedRegEvento/infPedReg/tpAmb`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN EVENTO_PED.REG.EVENTO

## Com o @useinvio/nfse-sdk

O `tpAmb` do evento difere do ambiente de envio. Os builders de evento do SDK usam o `ambiente` da chamada; veja [Ambientes](../referencia/ambientes.md).

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E1845`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
