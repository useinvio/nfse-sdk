# E0014: Conjunto de Série, Número, Código do Município Emissor e CNPJ/CPF informado nesta DPS já…

Rejeição **E0014** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Conjunto de Série, Número, Código do Município Emissor e CNPJ/CPF informado nesta DPS já existe em uma NFS-e gerada a partir de uma DPS enviada anteriormente.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/serie`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e

## Com o @useinvio/nfse-sdk

Essa rejeição aparece quando a mesma DPS (série + número) é enviada de novo. Se você reenviou depois de um timeout, a primeira tentativa pode ter sido autorizada: use `recuperarNfsePorDps(dpsId, certificado)` para obter a nota em vez de criar outra. Veja [Recuperar uma emissão após timeout](../guias/recuperar-emissao.md). Para uma nota nova, incremente `nDPS`.

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E0014`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
