# E1991: A assinatura deve ser feita com o certificado digital do emitente do Pedido de Registro d…

Rejeição **E1991** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo II - Leiaute e Regras de Negocio de Eventos v1.01 (22/01/2026).

## Mensagem oficial

> A assinatura deve ser feita com o certificado digital do emitente do Pedido de Registro de Evento.

## Onde se aplica

- Campo no XML: `evento/pedRegEvento/Signature`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN EVENTO_PED.REG.EVENTO

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E1991`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
