# E1581: Valor do diferimento para a CBS incorreto.

Rejeição **E1581** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Valor do diferimento para a CBS incorreto.

## Regra de negócio

> O valor do diferimento para a CBS deve ser igual ao valor total/IBSCBSTot/gCBS/vDif retornado pela Calculadora

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/IBSCBS/totCIBS/gCBS/vDifCBS`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e
