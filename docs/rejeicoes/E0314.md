# E0314: O código de tributação municipal informado não existe ou não está administrado pelo munic…

Rejeição **E0314** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> O código de tributação municipal informado não existe ou não está administrado pelo município de incidência do ISSQN na data de competência informada na DPS,

## Regra de negócio

> Verificar se o código de tributação municipal informado existe e está administrado pelo município de incidência do ISSQN na data de competência informada na DPS.
>
> Exceto quando o emitente da DPS for MEI na data de competência da emissão da NFS-e.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/serv/cServ/cTribMun`
- Nível 3: regra municipal, conforme a parametrização do município.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E0314`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
