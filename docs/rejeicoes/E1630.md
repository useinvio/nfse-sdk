# E1630: Arquivo enviado com erro na assinatura.

Rejeição **E1630** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> Arquivo enviado com erro na assinatura.

## Regra de negócio

> A assinatura da NFS-e deve ser válida.

## Onde se aplica

- Campo no XML: `NFSe/Signature`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e

## Explicar no seu código

```ts
import { emitirNfse, EmitirNotaError, explicarErros } from '@useinvio/nfse-sdk';

try {
  await emitirNfse(nota, certificado);
} catch (error) {
  if (error instanceof EmitirNotaError) console.table(explicarErros(error.erros));
}
```

No terminal: `npx -p @useinvio/nfse-sdk nfse explain E1630`. Para agentes de IA, a ferramenta MCP `explain_rejection` devolve este mesmo texto.
