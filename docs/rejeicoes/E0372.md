# E0372: O grupo de informações de obra não é permitido quando o código de tributação nacional não…

Rejeição **E0372** da NFS-e Nacional (SEFIN/ADN), com o texto oficial de Anexo I - Leiaute e Regras de Negocio DPS/NFS-e v1.01 (09/02/2026).

## Mensagem oficial

> O grupo de informações de obra não é permitido quando o código de tributação nacional não pertencer a algum dos subitens 07.02.01, 07.02.02, 07.04.01, 07.05,01, 07.05.02, 07.06.01, 07.06.02, 07.07.01, 07.08.01, 07.17.01, 07.19.01, 1414.03 e 14.14.04 da lista de serviços, com exceção do código 99.01.01.

## Regra de negócio

> Se o código de tributação nacional não pertencer a algum dos subitens 07.02.01, 07.02.02, 07.04.01, 07.05,01, 07.05.02, 07.06.01, 07.06.02, 07.07.01, 07.08.01, 07.17.01, 07.19.01, 14.14.03 e 14.14.04 da lista de serviços, então o grupo de informações de obra não é permitido.
> *Exceção: O grupo de informações de obra pode ser informado se o código de tributação nacional for o 99.01.01.

## Onde se aplica

- Campo no XML: `NFSe/infNFSe/DPS/infDPS/servobra`
- Nível 1: regra de consistência do leiaute.
- Planilha: RN DPS_NFS-e
