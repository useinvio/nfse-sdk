NFS-e Nacional · TypeScript

Você manda o JSON.
O SDK emite a nota.

Monta a DPS, valida no XSD oficial, assina com o seu certificado A1 e envia para a SEFIN. Sem XML na mão e sem nada para instalar no sistema.

npm install @useinvio/nfse-sdk
Testar no navegador → 
import { emitirNfse, NfseCertificate } from '@useinvio/nfse-sdk';

const certificado = NfseCertificate.fromEnv();

const { chaveAcesso } = await emitirNfse({
  ambiente: 'restrita',
  prestador: { cnpj: '12345678000195', ... },
  servico: { xDescServ: 'Desenvolvimento de software', ... },
  emissao: { valores: { vServ: '1500.00' }, ... },
}, certificado);

console.log('Nota emitida! 🎉', chaveAcesso);
JSON→DPS→XSD oficial→Assinatura A1→mTLS→SEFIN→Resposta tipada

O que vem na caixa

✅Valida antes de enviar

Erros apontam o campo exato do JSON, não uma linha perdida no XML.

🛟Nunca duplica nota

Envios não são repetidos às cegas. Depois de um timeout, o SDK pergunta à SEFIN o que aconteceu.

💬Rejeições explicadas

Cada código da SEFIN vem com o texto oficial e uma dica do que corrigir.

🧪Testa sem certificado

Uma SEFIN simulada roda no seu CI, sem rede e sem nota de verdade.

🤖Pronto para IA

Servidor MCP e plugin do Claude Code. Você aprova cada envio e o certificado nunca chega ao modelo.

🔐Certificado protegido

A chave privada nunca aparece em logs, e cada emitente tem a sua própria conexão.

O SDK fala o protocolo, mas não decide nada por você: códigos de serviço, alíquotas e regime ficam com a sua aplicação e o seu contador.
